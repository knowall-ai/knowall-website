== Common Issues

[cols="1,2", options="header"]
|===
| Problem | Solution

| Azure website not responding (timeout) but App Service shows "Running"
| Perform a full stop/start cycle (not just restart): +
`az webapp stop --name knowall-website --resource-group KnowAllAIRG` +
`az webapp start --name knowall-website --resource-group KnowAllAIRG` +
 +
To prevent recurrence, enable "Always On": +
`az webapp config set --name knowall-website --resource-group KnowAllAIRG --always-on true`

| Sallie answers every message with "I'm currently experiencing some technical difficulties"
| The chat provider call is failing. The log stream prints `Chat provider: azure` or `Chat provider: openai` per request,
so first confirm which backend is in use. On Azure, check the App Service settings `AZURE_OPENAI_ENDPOINT` /
`AZURE_OPENAI_API_KEY` (`az webapp config appsettings list --name knowall-website --resource-group KnowAllAIRG`) and the
upstream error; an HTTP 400 means the deployment or parameter shape has drifted (see xref:AZURE-OPENAI.adoc[Azure OpenAI]).
If it says `openai`, the Azure settings are missing or rejected and the `OPENAI_API_KEY` fallback is in use: check that key
and the OpenAI project's usage limits.

| Sallie says she is "rather popular right now" / has "used up my capacity for the minute"
| The provider returned HTTP 429. On Azure that is the deployment's tokens-per-minute cap, the spend ceiling working as
intended: raise it if traffic is legitimate with `scripts/azure-openai-capacity.sh 10` (units of 1,000 TPM). On the
OpenAI fallback it is an OpenAI rate or quota limit, which is managed on the OpenAI project.

| Sallie's voice is silent, or the mic falls back to typing
| Check the App Service settings `AZURE_OPENAI_VOICE_ENDPOINT` / `AZURE_OPENAI_VOICE_API_KEY` and the log stream for
`Error in speak API (azure)` / `Error in listen API (azure)`. A 429 means a voice deployment's capacity or the app's daily
voice budget (`SALLIE_BUDGET_SPEAK_PER_DAY`) was hit. If the log says `(openai)`, the Azure voice settings are missing or the
endpoint failed the app's Azure-host validation. If an `(azure)` entry shows an authentication error, check
`AZURE_OPENAI_VOICE_API_KEY` and `AZURE_OPENAI_VOICE_ENDPOINT`. See xref:AZURE-OPENAI.adoc[Azure OpenAI].

| Shop order service issues (no invoices sent, key refusal at startup, dedup store)
| See xref:ORDER-SERVICE.adoc[Order Service Operations] — the order daemon runs separately from the website deploy.

|===
